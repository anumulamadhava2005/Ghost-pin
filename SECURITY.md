# Security Policy 🔒

## Supported Versions

The following versions of GhostPin are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The GhostPin maintainers take the security of our application and users seriously.

If you discover a security vulnerability in GhostPin, please do **not** open a public issue. Instead, please follow this disclosure process:

1. **Email or Private Disclosure**: Submit a security advisory via [GitHub Security Advisories](https://github.com/anumulamadhava2005/Ghost-pin/security/advisories/new) or contact the project maintainer directly.
2. **Details to Include**:
   - Description of the vulnerability.
   - Exact steps to reproduce or proof-of-concept code/payload.
   - Affected devices, Android OS versions, or build variants.
   - Potential impact of exploitation.
3. **Response Timeline**:
   - You will receive an acknowledgement within 48–72 hours.
   - We will provide regular updates as we investigate and develop a patch.
   - Once a fix is verified, a release will be issued along with proper attribution to the reporter (unless you request anonymity).

Thank you for helping keep GhostPin safe for everyone!
